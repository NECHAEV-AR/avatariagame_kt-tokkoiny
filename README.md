# TOKCOINS — сайт накопительной системы Аватария KlipTok

## Файлы
- `index.html` — главная страница сайта.
- `assets/tokcoin-logo.png` — фирменная монета ТокКоина с прозрачным фоном.
- `assets/tokcoins-hero.jpg` — предоставленный визуальный референс с персонажами Аватарии.

## Публикация на GitHub Pages
1. Создайте репозиторий GitHub, например `tokcoins`.
2. Загрузите в корень репозитория файл `index.html` и папку `assets` целиком.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. После публикации GitHub покажет адрес сайта.

Сайт не требует сборки, npm или дополнительных библиотек. Тексты, ссылки и оформление можно менять непосредственно в `index.html`.
