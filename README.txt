ТОККОИНЫ | НАКОПИТЕЛЬНАЯ СИСТЕМА

Файлы сайта для GitHub Pages:
- index.html — содержимое сайта
- style.css — оформление
- script.js — каталог, поиск и сортировка
- images/hero.jpg — фон главного экрана
- images/tokcoin.png — оригинальный знак ТокКоина с прозрачным фоном

Публикация:
1. Загрузите все файлы и папку images в корень репозитория GitHub.
2. В Settings → Pages выберите Deploy from a branch, ветку main и папку /(root).
3. Дождитесь завершения публикации GitHub Pages.

В каталоге пока стоят белые заглушки товаров. В архиве победителей оставлен демонстрационный шаблон месяца и даты — реальные даты и списки нужно будет добавить по мере появления данных.
